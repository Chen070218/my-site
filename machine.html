Machine · two toys

The pointless machine, and a game

The first machine exists only to switch itself off. The second one exists only to be played with for thirty seconds. Both are here to practise state, timers and the small details that make an interface feel alive.

01 — The useless machine

There is exactly one switch

Off. It is waiting for you to make the first move.

The rule of a useless machine is simple: you switch it on, an arm comes out and switches it off again. It has no other purpose. The version above uses one class, one timeout and a rotation.

02 — Bug squash

A bug is hiding somewhere in the grid. It jumps to a new cell every second. Click or tap it before it moves. Thirty seconds, keyboard friendly.
