Six things I would build next

Learning goes faster when the next exercise is something I actually want to use. Each idea below names the skill it would force me to practise, and why it is worth the time.

Campus weather wall

Intermediate

A page that combines the current weather at the campus with the last photo I took there. It would refresh every ten minutes and show a short sentence instead of a wall of numbers.

  • Fetch API and JSON
  • Loading and error states
  • Responsive image pairing

Study timer garden

Starter

A pomodoro timer where every finished session grows a plant on a small grid. The plants live in localStorage, so the garden survives a reload.

  • Timers and state
  • localStorage
  • CSS grid and transforms

Course notes search

Intermediate

A single page that loads my course notes and filters them as I type. No server: the notes are an array in one file, and the search highlights the matching words.

  • Arrays and filter
  • Event handling
  • Accessible search fields

Where did my week go

Intermediate

A check-in heat-map: one square per day, darker where I studied longer. It would make the invisible weeks visible, and it is a good excuse to practise data shapes and colour scales.

  • Data modelling
  • CSS colour scales
  • Dates in JavaScript

An accessibility field guide

Ambitious

An interactive checklist for the things I keep forgetting: focus order, labels, contrast, reduced motion. Each item would come with a small live example that shows the good and the bad version.

  • Forms and ARIA
  • Keyboard testing
  • Teaching by example

Tiny CSS gallery

Starter

A gallery of small scenes drawn with nothing but CSS: gradients, shadows and a lot of pseudo-elements. No image files at all, which makes it a good test of how far layout primitives can go.

  • Gradients and shadows
  • Pseudo-elements
  • Creative constraints

Pick one, keep the scope small, and write down what broke. The notes are more useful than the finished page.
