About this notebook

Field Notes is the learning website for my Web Technologies course. It is not a portfolio and it is not a product: it is a place to practise the three languages of the web and to write down what each one taught me.

Who writes it

I am Chen Xiangyang, a Computer Science student in the 2025 intake at Hainan Bielefeld University of Applied Sciences. I am learning programming, algorithms and operating systems, plus German and English. This site is the smaller of my two course projects; the larger one is my personal site.

How it is built

Every page is hand-written HTML. There is no framework, no package manager and no build step: the files in this repository are exactly what the browser receives. One stylesheet holds the whole visual system, and three small scripts handle the navigation, the random quote and the machine page.

The navigation is the clearest example of the approach. It lives once in nav.html; nav.js fetches that fragment and inserts it into every page, then marks the current page with aria-current. Adding a page means editing one file instead of five.

Decisions I made

  • Paper instead of glass. The palette is warm paper, ink, vermilion and teal. The grid in the background is drawn with two CSS gradients, so the whole texture costs no image request.
  • Semantic HTML first. Landmarks, one h1 per page, heading levels in order, real blockquote and cite elements on the quotes page, and buttons that are actually buttons.
  • Accessibility as a constraint, not a checklist. The skip link, visible focus, labelled tiles, live status messages, and a keyboard-playable game came before the decoration. Every animation has a reduced-motion version.
  • No third-party images or fonts. The hero map and the icons were drawn for this project with a short Python script; the type is whatever the system already has. That keeps the site fast and avoids licence questions.
  • Small state only. The bug game keeps its best score in localStorage. Nothing else is stored and there is no tracking.

What I would change

I would like the quotes page to remember the last quote instead of choosing a new one on every visit, and I would make the bug game slightly harder each round. The layout would also benefit from a real content page — one long note — to test the reading styles at a length this site does not have yet.
